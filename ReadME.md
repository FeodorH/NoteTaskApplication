# NoteTask

**NoteTask** — это современное Android-приложение для управления заметками и задачами.
Оно сочетает в себе удобный интерфейс, мощные инструменты организации и интеллектуальные возможности,
такие как голосовой ввод и генерация задач с помощью нейросети.

Приложение разработано с акцентом на качество кода, архитектурную чистоту и использование актуального стека технологий.

---

## 🚀 Основные возможности

- **Заметки**

   - Создание, редактирование и удаление заметок.

   - Добавление изображений (камера или галерея).

   - Поиск по заголовку и сортировка (по дате создания).

   - Режим массового удаления.

- **Задачи**

   - Управление списком задач с отметкой о выполнении.

   - Фильтрация по статусу (активные / выполненные / все).

   - Быстрое добавление задачи прямо в списке.

   - Интеллектуальное создание задачи из голосовой команды (с помощью GigaChat).

- **Голосовой ввод**

   - Распознавание речи через Google Speech Recognizer (при наличии сервисов).

   - Автоматическое переключение на офлайн-движок **Vosk**, если Google недоступен.

   - Голосовой ввод для текста заметок и создания задач.

- **Настройки**

   - Выбор темы (светлая / тёмная / системная).

   - Выбор акцентного цвета (6 вариантов).

   - Отображение баланса токенов GigaChat.

   - Сброс всех настроек.

## 🧱 Архитектура

Проект построен на принципах **Clean Architecture**, что обеспечивает:

- Разделение ответственности между слоями: **data**, **domain**, **presentation**.

- Независимость бизнес-логики от внешних фреймворков и устройств.

- Высокую тестируемость и поддерживаемость.


**Взаимодействие слоёв:**

- **Presentation** (Compose UI + ViewModel) подписывается на состояние через `StateFlow`.

- **ViewModel** вызывает Use Case'ы из **domain**.

- **Use Case'ы** используют репозитории из **data**, которые работают с Room и Retrofit.

- Для реактивности применяется `combine` для объединения потоков (например, список + поиск + сортировка).

## 📦 Установка и запуск

1. Клонируйте репозиторий:

   bash

   git clone https://github.com/FeodorH/NoteTaskApplication

2. Откройте проект в **Android Studio (Koala или новее)**.

3. В файле `local.properties` укажите учётные данные для GigaChat:

   properties

   GIGACHAT_CLIENT_ID=ваш_client_id
   GIGACHAT_CLIENT_SECRET=ваш_client_secret

4. Убедитесь, что модель Vosk (папка `vosk-model-small-ru-0.22`) присутствует в `app/src/main/assets/`.
5. Если её нет, скачайте с [официального сайта](https://alphacephei.com/vosk/models) и поместите туда.

5. Нажмите **Sync Now** в Gradle, затем выполните **Build → Rebuild Project**.

6. Запустите приложение на устройстве с Android 7.0+ или на эмуляторе.

## 📌 Примечания

- Для работы камеры и галереи запрашиваются соответствующие разрешения.

- Все данные (заметки, задачи, настройки) сохраняются локально и восстанавливаются после перезапуска.

- GigaChat используется только для генерации задач из голоса; баланс токенов отображается в настройках.

- Офлайн‑распознавание Vosk (~40 МБ) копируется во внутреннее хранилище при первом запуске.

- В текущей версии для упрощения тестирования отключена проверка сертификатов (в продакшене это необходимо настроить корректно).
