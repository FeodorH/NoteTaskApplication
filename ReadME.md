# NoteTaskApplication

---

### 📌 Краткое описание

Тестовое Android-приложение для управления заметками и задачами. Поддерживает создание, редактирование, удаление, поиск, сортировку, а также голосовой ввод и настройку темы. Реализовано с использованием современного стека: **Jetpack Compose, Clean Architecture, MVVM, Room, Retrofit, Hilt, Vosk (офлайн-распознавание)**.\

Ссылка на чистую историю разработки с deepseek: https://chat.deepseek.com/share/ays0jmlyx5dv7x8uqv

---

### 🧩 Функциональные возможности

#### Заметки

- Список заметок с превью (изображение, заголовок, дата).

- Поиск по заголовку (мгновенная фильтрация).

- Сортировка: от новых к старым / от старых к новым.

- Режим массового удаления.

- Создание/редактирование: заголовок, текст, изображение (галерея или камера).

- Голосовой ввод текста : Поддерживаются 2 формата: через стандартное гугл распознавание и
- через внутреннюю модель Vosk - в случае недоступности Google.

#### Задачи

- Список задач с чекбоксом и статусом (активная / выполненная).

- Фильтрация по статусу (все / активные / выполненные).

- Поиск по названию.

- Добавление задачи прямо в списке (текстовый ввод).

- Голосовое создание задачи с обработкой через **GigaChat**(нейросеть формирует задачу из голосового запроса).


#### Настройки

- Переключение темы: светлая / тёмная / системная.

- Выбор акцентного цвета (5 предустановок + стандартная).

- Отображение баланса токенов GigaChat (с загрузкой и обработкой ошибок).

- Сброс настроек.


#### Голосовой ввод

- Использует **Android SpeechRecognizer** (при наличии Google Play Services).

- Резервный вариант – **Vosk** (офлайн-распознавание на устройстве).

- Для задач: распознанный текст отправляется в GigaChat для преобразования в задачу.

### 🏗️ Архитектура

Проект построен по принципам **Clean Architecture** с разделением на слои:

- **`data`** – локальные и удалённые источники данных (Room, Retrofit, репозитории).

- **`domain`** – бизнес-модели, интерфейсы репозиториев и use case'ы.

- **`presentation`** – UI-слой на Compose (экраны, ViewModel, состояния).


ViewModel управляют состоянием UI через `StateFlow`, взаимодействуя с use case'ами. Для реактивности используется `combine` для объединения потоков (список + поиск + сортировка).

### 🚀 Сборка и запуск

1. Клонируйте репозиторий.

2. Откройте проект в **Android Studio (Koala или новее)**.

3. В файле `local.properties` укажите:

   ```text
   GIGACHAT_CLIENT_ID=<ваш_client_id>
   GIGACHAT_CLIENT_SECRET=<ваш_client_secret>
   ```

4. Поместите модель Vosk в `app/src/main/assets/vosk-model-small-ru-0.22`(если её там нет) (при первом запуске она скопируется автоматически).

5. Нажмите **Sync Now** и соберите проект (`Build → Rebuild Project`).

6. Запустите приложение на эмуляторе или реальном устройстве (требуется Android 7.0+).

### 📝 Примечания

- Проект пока не готов к прод среде полностью т.к. я пока не подключил сертификаты GigaChat, и оставил настройку доверия всем сертификатам включённой.

- **GigaChat** используется только для генерации задач из голоса. Баланс отображается в настройках.

- **Vosk** – запасной вариант распознавания (офлайн). Модель (~40 МБ) копируется во внутреннее хранилище при первом запуске.

- Для работы камеры и галереи запрашиваются соответствующие разрешения.

- Все данные сохраняются локально (Room) и восстанавливаются после перезапуска.
